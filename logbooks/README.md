# LGAD Logbooks

This directory contains experimental logbooks documenting LGAD (Low-Gain Avalanche Detector) experiments and measurements.

## Purpose

These logbooks provide:
- **Comprehensive documentation** of experimental campaigns
- **Data provenance** and location information
- **Technical specifications** of hardware and measurements
- **Analysis context** and experimental objectives
- **Progressive extension** as experiments evolve

## Format

Logbooks are written in **Markdown** format for:
- Human readability in any text editor
- Version control compatibility (trackable in git)
- Compatibility with AI analysis tools
- Easy conversion to other formats (HTML, PDF, etc.)
- Support for embedded code blocks and technical details

## Naming Convention

Logbooks follow the pattern: `LGAD_YYYY_MM_DD_[Experiment_Name].md`

Example: `LGAD_2026_04_08_LTE_Noise.md` - LGAD experiment on April 8, 2026, measuring LTE noise

## How to Extend Logbooks

When updating a logbook:

1. **Open the relevant markdown file**
2. **Add new sections** as needed (use clear headings)
3. **Keep both AI and human readability** in mind:
   - Use proper Markdown syntax
   - Include structured tables for data
   - Add code blocks for technical details
   - Document assumptions and decisions
4. **Track changes** through git commits
5. **Date and version** your updates in the metadata section

## Integration with Analysis

- Link to relevant Python scripts and notebooks
- Reference data files and their locations
- Document analysis results and findings
- Cross-reference related measurements
